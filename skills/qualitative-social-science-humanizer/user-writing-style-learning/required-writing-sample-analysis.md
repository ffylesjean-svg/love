# Required User Writing-Sample Analysis

This module controls mandatory author-voice learning. Use it before every first-pass revision and reuse its stored output during every second pass in the same project.

## Mandatory source requirement

The user must provide at least one genuine sample of their own previous academic writing through the Codex conversation. More than one sample is preferable when it helps distinguish stable habits from a single document's local demands, but do not impose a fixed maximum.

Do not proceed when no genuine user sample is available. Never substitute:

- Codex-generated prose;
- prose generated by another AI system;
- the target manuscript by itself;
- participant quotations;
- copied scholarship or a reference list;
- material whose author-written portions cannot be distinguished;
- bundled or fictional writing demonstrations.

If a sample is co-authored or edited heavily, use only the portions that the user identifies as representative of their own writing. Ask for clarification when provenance is uncertain.

## Store the source samples

Before analysis:

1. save exact, unedited copies in the current project's `qualitative-social-science-revision-data/user-provided-writing-samples/` folder;
2. keep the original filename when safe and add a unique suffix if a name already exists;
3. record the stored filename, source attachment, and user-supplied provenance in the current input record;
4. do not modify, normalise, or annotate the stored source copy;
5. do not move the sample into the open-source Skill repository.

Retain these samples for future work in the same project unless the user asks to remove them. Never reuse them for another project or another user's work.

## Analyse writing habits

Separate the user's own prose from quotations, source text, references, tables, appendices, and other people's contributions. Analyse tendencies across the eligible prose in these dimensions:

| Dimension | Observe |
| --- | --- |
| Sentence rhythm | Typical density, coordination, subordination, and purposeful departures |
| Paragraph development | How claims, context, evidence, qualification, and interpretation are sequenced |
| Transitions | Whether links are explicit, content-led, contrastive, cumulative, or implicit |
| First person | Where the author uses first-person, reflexive, or impersonal forms |
| Hedging | Strength, frequency, and placement of epistemic qualification |
| Theoretical exposition | How concepts are introduced and connected to material |
| Quotation integration | Lead-ins, attribution, follow-up analysis, and spacing |
| Vocabulary and register | Recurring levels of formality, reporting-verb preferences, and technical precision |
| Punctuation | Use of semicolons, colons, parentheses, dashes, and quotation conventions |
| Information order | Where the author places context, claims, evidence, and qualifications |
| English variety | Consistent spelling and punctuation conventions |

Distinguish stable patterns from one-off choices, assignment requirements, errors, or borrowed language. Weight samples closer to the target genre and discipline more heavily, and lower confidence when samples conflict.

## Create the persistent author-style profile

Write `qualitative-social-science-revision-data/learned-user-writing-style/author-writing-style-profile.md` before revising the target manuscript. The profile must record:

- stored sample filenames and the eligible scope analysed;
- confidence and any provenance limitations;
- English variety;
- sentence and paragraph rhythm;
- transition habits;
- first-person and reflexive practice;
- hedging practice;
- theoretical exposition;
- quotation integration;
- vocabulary and register tendencies;
- punctuation, syntax, and information order;
- features that should not be normalised away;
- generic habits absent from the samples that should not be imposed.

Describe tendencies abstractly. Do not place reusable sentence banks, long excerpts, distinctive phrases, or imitable templates in the profile.

When new genuine samples arrive, preserve the previous profile, analyse the new evidence, and create an updated profile with a clear provenance record.

## Apply the profile

- Treat the profile and stored samples as the primary author-voice reference.
- Match habits only where they fit the current argument, evidence, and manuscript section.
- Prefer the user's demonstrated ways of qualifying claims, moving between evidence and interpretation, and integrating quotations.
- Do not mechanically copy sentences, memorable strings, distinctive phrases, or entire sentence structures.
- Do not reproduce an error merely because it appears in a sample.
- Do not impose a statistical sentence-length formula or manufacture irregularity.
- Do not let voice matching weaken attribution, citation scope, theoretical precision, hedging, or research integrity.

If the user samples do not support a confident style decision, preserve the target manuscript's wording where safe and flag the uncertainty. Do not fill the gap with a Codex-generated writing style.

## Second-pass use

During Turnitin-informed second-pass review, reread the stored profile and consult the stored user samples as needed. Apply them only within mapped flagged passages. The first-pass manuscript remains the comparison baseline, and all non-flagged passages remain locked by default.
